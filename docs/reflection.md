# Reflection

In this project, I was able to see how GitHub could be used for organizing the software project. This includes learning how to create repositories, use issues to manage tasks and use labels and assignees to clearly distribute responsibility. Also, I found out how branches could help me to develop new features without impacting the project itself.

It was difficult for me to understand the connection between branches, commits and pull requests at first. After learning how to use these features, I understood that commits allowed me to track every change separately while pull requests made possible reviewing changes made in a feature branch before merging them into the main branch.

The most enjoyable part of this experience was development of my project in stages and tracking all my progress along the way. If I had more time, I would have improved the design of my dashboard and added more features to it.
