# NASA Space Weather Dashboard

## Project Idea
NASA Space Weather Dashboard is a web-based system that is designed to allow the users learn more about space weather.

Space weather involves phenomena like solar activity which can have an impact on satellites and even communication systems.

The main objective of this system is to provide space weather information in a simple manner through a webpage.

## How It Helps NASA / Space
The goal of the project is to increase awareness of space weather and the importance of monitoring activities in space.

It will enable students to see how activities in space impact technologies both here on earth and in space.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub

## How to Run the Project
1. Clone/download the repository.
2. Navigate to the project directory.
3. Locate 'index.htm'.
4. Load `index.html` in your web browser.
5. Experience the Space Weather Dashboard.
